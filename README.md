Overview

The data of different types of wine sales in the 20th century was analysed. The data was read as an appropriate Time Series data and was plotted.All the exponential smoothing models on the training data were built and the model was evaluated using RMSE on the test data. 
Other additional models such as regression, naïve forecast models, simple average models, moving average models were also built on the training data and their performance was checked on the test data using RMSE.An automated version of the ARIMA/SARIMA model was built.
Based on the model-building exercise, the most optimum model(s) were built on the complete data and 12 months were predicted into the future with appropriate confidence intervals/bands.
